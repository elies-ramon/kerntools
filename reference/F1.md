# F1 score

\`F1()\` computes the F1 score between the output of a classification
prediction model and the actual values of the target.

## Usage

``` r
F1(ct, multi.class = "macro")
```

## Arguments

- ct:

  Confusion Matrix.

- multi.class:

  Should the results of each class be aggregated, and how? Options:
  "none", "macro", "micro". (Defaults: "macro").

## Value

F1 (a single value).

## Details

F1 corresponds to the harmonic mean of Precision and Recall.

## Examples

``` r
y <- c(rep("a",3),rep("b",2))
y_pred <- c(rep("a",2),rep("b",3))
ct <- table(y,y_pred)
F1(ct)
#> [1] 0.8
```
